# Portfolio

Base de Next.js para el portfolio personal.

## Stack inicial

- Next.js + TypeScript
- Tailwind CSS
- Motion
- Cloudflare Workers mediante OpenNext

## Comandos

- `npm run dev`: desarrollo local.
- `npm run build`: build de Next.js.
- `npm run preview`: prueba la aplicación en el runtime de Cloudflare.
- `npm run deploy`: despliegue a Cloudflare Workers.

## Contenido

Los datos editables se centralizan en `src/content/` para evitar incorporar un CMS antes de necesitarlo.

## Referencias de Stitch

Los archivos de diseño importados desde el proyecto **Organic Tech Portfolio System** están en:

- `docs/design.md`: sistema de diseño y tokens visuales.
- `stitch/reference/`: HTML de referencia para desktop, mobile y shader, más especificaciones de animación y accesibilidad.
- `stitch/assets/`: recursos de imagen de referencia.

Estos archivos son fuentes de implementación: no se sirven directamente desde la aplicación.
